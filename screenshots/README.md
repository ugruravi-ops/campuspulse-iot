# 📸 Screenshots & Media

Add your project photos here once you build the prototype. GitHub renders them automatically when linked from the main README.

## Recommended shots (in this order)

| Filename | What to capture |
|----------|-----------------|
| `hardware-breadboard.jpg` | Full breadboard setup, clean lighting, on a desk |
| `serial-monitor.png` | Arduino IDE Serial Monitor showing live readings |
| `thingspeak-dashboard.png` | ThingSpeak channel with live charts (all 4 fields) |
| `alert-triggered.jpg` | Red LED lit while AQ value spikes on monitor |
| `field-deployment.jpg` | Node deployed outside/near a window on power bank |

## How to add

1. Commit images into this `screenshots/` folder.
2. Link them from the main `README.md`:

```markdown
### Hardware
![Breadboard setup](screenshots/hardware-breadboard.jpg)

### Live Dashboard
![ThingSpeak charts](screenshots/thingspeak-dashboard.png)
```

## Photo tips (makes the project look 10× more professional)

- Shoot in **daylight**, white desk/bedsheet background, phone camera is fine
- No messy cables in frame — tidy the breadboard first
- Include one **close-up** of the sensor side and one **wide shot** of the whole setup
